# Responsible AI

## Employee Intelligence Knowledge Graph

This project focuses on organizing employee-related information into a structured knowledge graph using MySQL and Neo4j.

### Technologies Used
- Python
- MySQL
- Neo4j
- Knowledge Graph
- Unstructured Data Processing

### Project Structure
- `mysql_to_neo4j.py` — Processes MySQL data and transfers it to Neo4j.
- `unstructured_to_neo4j.py` — Processes unstructured documents and extracts useful information.
- `extracted/` — Contains extracted text and image resources.
- `resumes/` — Contains resume-related files.

### Objective
To transform employee information from structured and unstructured sources into a connected knowledge graph that can support intelligent information retrieval and analysis.
